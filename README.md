# Sales Ledger — Dual-Database Federated Data & Replication Console

**Sales Ledger** is a  web application built for a distributed data systems assignment demonstrating heterogeneous storage across a relational **SQL** database (**SQLite**) and a document **NoSQL** database (**NeDB**). It implements deterministic 1/3 + 1/3 + 1/3 data partitioning, federated & store-specific search with deduplication, full 36-field record creation and editing, and a versioned cross-database replication protocol with an auditable **Replication Protocol Log**.
